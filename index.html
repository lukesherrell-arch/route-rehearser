            How it works

            1. Type where you start and where you're going, then Find route.
            2. If it's not the way your instructor goes, tap + Via point then tap the road it should use. Drag a numbered pin to move it.
            3. If the route stops short (e.g. on the main road instead of in the car park), tap Move end then tap exactly where you want to finish. Move start works the same way.
            4. Rehearse walks you along the route in Street View. Step with ◀ ▶ (or the left/right arrow keys), or press the blue ▶ to play.
            5. ⏮ ⏭ jump to just before the previous / next checkpoint, to skip dull straight bits (up/down arrow keys).
            6. Faster speeds take bigger jumps rather than shorter looks, so pictures have time to sharpen. Play slows to every picture near a checkpoint.
            7. The blue line on the road shows where the route goes. It assumes flat ground, so it can drift a bit on hills. Turn it off with Line.
            8. You can drag the picture to look around. Recentre faces you back down the road.
            9. Grey on the slider = no Street View there, so it skips that bit. Orange marks = checkpoints.
            10. The green banner shows the next manoeuvre and which lane. The map follows you like a sat-nav.
            11. Checkpoints are added automatically at each junction with a tip. Use 📍 Pin here to add your own (box junctions, tricky bits).
            12. 🎲 Random makes a practice route round an area: give a start, how far out (miles) and/or about how long (minutes). 🎲 Another makes a different one with the same settings. Save the ones you like.
            13. Routes are saved on this device. To share them between your PC and phone, set up cloud saving (below) once on each.
            14. On a wide screen the sat-nav sits beside the picture. ⤡ makes it small; click the small map to bring it back.
            15. Lane arrows, speed limits, lights and crossings come from OpenStreetMap, a free volunteer-made map. Some roads have them and some don't, and they can be out of date, so always go by the real signs and markings.

            Setting up cloud saving

            1. On github.com, make a new repository called route-rehearser-data. Choose Private.
            2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
            3. Repository access: Only select repositories → route-rehearser-data. Permissions → Repository → Contents: Read and write.
            4. Copy the token, then in this app open Routes, type the repository as your-name/route-rehearser-data, paste the token and press Connect. Repeat on your other device.

            The token stays in this browser only. It can only reach that one repository.
